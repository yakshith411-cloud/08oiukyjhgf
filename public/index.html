Supabase Cloud Database & Auth

Meetflow connects directly to Supabase PostgreSQL for employee auth, attendance graphs, and scheduled executive meetings. When unconfigured, it safely falls back to local SQLite.

Supabase PostgreSQL URI (Port 5432 or Transaction pooler port 6543).
Step-by-Step Supabase Setup:
  1. Go to supabase.com ↗ and create a free project.
  2. Go to Project Settings > Database and copy the Connection string (URI). Replace [YOUR-PASSWORD] with your actual password and paste it above.
  3. Go to Project Settings > API and copy the Project URL and anon / public key into the fields above.
  4. Click Save & Connect Supabase. Meetflow auto-migrates and syncs all tables!
