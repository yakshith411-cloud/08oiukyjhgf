Checking Database…

Database & Auth (Supabase & Neon)

Meetflow connects to Supabase or Neon PostgreSQL to store employee profiles, authentication credentials, monthly attendance graphs, and boss meeting schedules. When unconfigured, it safely falls back to local SQLite.

Supabase connection string (Port 5432 or Pooler 6543) or Neon DB URL.
Setup Instructions:
  1. Supabase: Go to supabase.com ↗ > Project Settings > Database > Connection String (URI).
  2. Neon DB: Go to neon.tech ↗ > Dashboard > Connection Details > Postgres URI.
  3. Paste the connection string above and click Save Database & Supabase Settings.
