Neon Serverless PostgreSQL

Meetflow uses serverless PostgreSQL on Neon DB to securely store employee profiles, authentication sessions, and monthly attendance tracking. When unconfigured, it uses a local SQLite fallback database.

How to get a free Neon DB URL:
  1. Sign up for free at neon.tech ↗.
  2. Create a new project (takes ~2 seconds).
  3. Copy the Connection string (Postgres URI) and paste it above.
